# Documentation Map

This directory is organized by documentation purpose so related material stays together.

## Sections

- `user_guides/`
  User-facing guides and operating manuals.
- `reference/`
  Stable technical and functional reference material.
- `product/`
  Product direction, priorities, and restructuring proposals.
- `research/`
  Research notes, empirical syntheses, and strategy evolution logs.
- `evaluation_ux/`
  UX reviews and evaluation lots.
- `adr/`
  Architecture decision records.

## Quick Pointers

- `user_guides/apps/`
  Dashboard guides for `optimal_tf`, `market_dashboard`, `portfolio_dashboard`, and `matrix_inspection_dashboard`.
- `user_guides/optimal_tf_usage.md`
  Main user manual for `optimal_tf`.
- `reference/`
  Architecture, specifications, strategy notes, and shared package reference.
